# LightningDiT training (legacy)

End-to-end LightningDiT training scripts (`train.py`, `inference.py`, `transport/`, `models/`) were removed in favor of the native Diffusers integration under `src/diffusers`.

For sampling and checkpoint conversion, see [README_DIFFUSERS.md](../README_DIFFUSERS.md).

For VA-VAE training, see [vavae/README.md](../vavae/README.md).

The original LightningDiT training workflow remains available in the upstream [HUST-VL/LightningDiT](https://github.com/hustvl/LightningDiT) repository.
